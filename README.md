# S Chicken

Website bài tập gồm 10 trang HTML, CSS và JavaScript thuần.

Mở thư mục [S-Chicken](S-Chicken), rồi chạy `index.html` bằng Live Server trong VS Code. Không cần npm hay backend.

- [Hướng dẫn chạy và bảng đối chiếu yêu cầu](S-Chicken/README.md)
- [Dàn ý PowerPoint và câu hỏi bảo vệ](S-Chicken/docs/BAO_CAO.md)
- [Mẫu Excel phân công (CSV UTF-8)](S-Chicken/docs/PHAN_CONG.csv)

Thông tin thương hiệu, tài khoản, đặt hàng và tuyển dụng đều là mô phỏng cho bài tập.

## Tải về

[Tải gói mã nguồn S-Chicken.zip](S-Chicken.zip), giải nén rồi mở thư mục `S-Chicken` bằng VS Code và chạy `index.html` với Live Server.

Bạn cũng có thể chọn **Code → Download ZIP** để tải toàn bộ kho.
