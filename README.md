# S Chicken — Professional Redesign

Website bài tập 10 trang HTML, CSS và JavaScript thuần; giao diện được thiết kế lại với ảnh món mới, font cục bộ, responsive và các tương tác mua hàng.

## Tải về và chạy

[Tải S-Chicken.zip](S-Chicken.zip), giải nén, mở thư mục `S-Chicken` bằng VS Code và chạy `index.html` với **Live Server**. Không cần npm, backend hoặc bước build.

Hoặc chọn **Code → Download ZIP** để tải cả kho.

- [Hướng dẫn chạy, giải thích mã và bảng đối chiếu yêu cầu](S-Chicken/README.md)
- [Audit và bàn giao bản thiết kế mới](S-Chicken/docs/REDESIGN.md)
- [Kết quả kiểm thử](S-Chicken/docs/KIEM_THU.md)
- [Dàn ý PowerPoint và hỏi đáp bảo vệ](S-Chicken/docs/BAO_CAO.md)
- [Mẫu phân công mở bằng Excel](S-Chicken/docs/PHAN_CONG.csv)

Thông tin cửa hàng, tài khoản, giao dịch và tuyển dụng đều là minh họa cho bài tập.
